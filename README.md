# The Commissioner Invitational

A single-page browser game (plain HTML, CSS and JavaScript, no build step).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub and upload everything in this folder (`index.html` and the `assets` folder) to the root.
2. Go to Settings > Pages, set Source to "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, then Save.
3. After a minute or two the game is live at `https://<your-username>.github.io/<repo-name>/`. Share that link with testers.

Note: GitHub Pages on a free account needs a public repository, so the player cards and course photos in `assets` become publicly viewable.
